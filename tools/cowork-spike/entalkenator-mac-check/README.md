# enTalkenator Mac check

A one-off test. It checks whether Cowork can reach a small helper that runs on your Mac, which
enTalkenator needs for the Keychain, the Mac's voices, and PDF handling. Install it, start a
Cowork task with any folder, and say "Run the enTalkenator Mac check". It changes nothing on
your Mac beyond writing and deleting one marker file in that folder. Remove it afterwards.
